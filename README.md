# BULLSEYE — Public Product Site

This repository contains the public informational site for **BULLSEYE**, a League of Legends competitive-intelligence, post-match analytics and coaching decision-support product.

It intentionally contains **no private product source code, team data, scrim data, raw provider payloads, credentials, secrets or internal infrastructure**.

The private BULLSEYE application repository remains separate.

Public site contents:

- `index.html` — product overview
- `privacy.html` — privacy policy
- `terms.html` — terms of use
- `riot.txt` — Riot Developer Portal product verification
- `styles.css` — public-site presentation only
