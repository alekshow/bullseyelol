Evidence for better review.
Context for better decisions.

BULLSEYE is a post-match analytics and coaching decision-support platform built for professional esports operations.

PRODUCT PRINCIPLE Descriptive, never conclusive.
01 · PRODUCT

Competitive analysis that remains auditable.

BULLSEYE helps coaches and analysts organize League of Legends data into evidence that can be inspected over time. It presents sample size, context, observed statistics, supporting matches and limitations while leaving interpretation and final decisions to the coaching staff.

The platform includes player profiles and dossiers, champion-pool analysis, match and VOD review, competitive-meta analysis, draft context, role-relative comparisons, player discovery and evidence/hypothesis workflows.

02 · RIOT API USAGE

Ranked context, not real-time gameplay assistance.

The Riot Games API is used as a complementary source for ranked League of Legends context. BULLSEYE uses account identity, ranked history, match/timeline data and ranked status to support historical and post-match analysis.

Account-V1Riot ID and PUUID resolution
Summoner-V4League account metadata
Match-V5Ranked match history and timelines
League-V4Ranked context
Spectator-V5Known-account in-game status only
Data DragonOfficial static game assets and metadata

Professional tournament, Tournament Realm and scrim data are obtained separately through authorized Riot-provisioned GRID access and remain governed as a separate data domain.

04 · STATUS

Active professional product development.

BULLSEYE is already functional as an internal analytical platform. Current engineering work focuses on continuous compute automation so newly authorized data can safely and deterministically update the appropriate analytical products.

The public site intentionally contains no private team data, source code, credentials, raw match payloads or confidential scrim information.
